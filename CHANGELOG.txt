WEBSITE RECORDING FILTERS
- Added independent browser capture toggles for Clicks, Scroll, Click Location, Text Input, and Selections
- Added quick presets: All Safe, Clicks Only, Click + Location, Scroll Only, Input Only, Selection Only
- Browser helper receives the app's saved website-filter defaults when generated
- Browser helper also lets filters be changed live while capturing
- Added debounced scroll recording for the page and scrollable elements
- Added semantic scroll replay using saved scroll positions
- Added opt-in non-sensitive text-input capture and replay
- Added dropdown, checkbox, radio, date, month, and week selection recording/replay
- Click coordinates can now be omitted for semantic-only click recording
- Smart Action exports preserve browser event type and scroll/input/selection details

PRIVACY / SAFETY
- Text input remains OFF by default
- Password/passcode/token/secret/API-key/authentication/OTP/verification-code/CVV/CVC/PIN/SSN-like fields are always blocked/redacted
- Sensitive fields are blocked from input replay

GITHUB SOURCE LAYOUT
- Added src_patches/v1_1_website_filters.pyfrag
- Source loader injects version patches immediately before main() starts
- EXE build now bundles src_patches
- Launcher validates the patched reconstructed source before starting
