# Release Checklist

For future Rice2k Macro Studio releases:

- Update version patch and launcher checks
- Run Python compile/import validation
- Smoke-test every main page
- Verify dark hover/focus/disabled/read-only states
- Verify page mouse-wheel scrolling
- Verify browser-helper JavaScript
- Verify error/startup logs
- Verify EXE build assets
- Update README, CHANGELOG, and VERSION_HISTORY
- Package the tested ZIP
