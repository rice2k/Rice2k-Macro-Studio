## Core workflow

```text
Choose what to record
        ↓
Record with F8
        ↓
Stop + Save with F9
        ↓
Review Smart Actions / Raw Actions
        ↓
Run Pre-flight if the macro matters
        ↓
Play with F12
        ↓
Export or refine as needed
```
