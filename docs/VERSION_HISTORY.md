## Current Release

### 🟦 v1.1 — Website Recording Filters
**Released:** September 16, 2026  
**Status:** Current

Focus: make browser recording selective, easier to understand, and safer to use.

Major additions:
- Independent browser recording toggles
- Clicks
- Scroll
- Optional click location
- Opt-in non-sensitive text input
- Dropdown/checkbox/radio/date selections
- Browser presets
- Semantic scroll replay
- Browser Smart Action categories
- Privacy-sensitive input blocking/redaction
- v1.1 patch-based GitHub source layout

Best new use cases:
- Scroll-only browser macros
- Semantic clicks without coordinates
- Browser form-selection workflows
- Ordinary non-sensitive input automation

# Development Lineage Before v1.0

Before the Rice2k Macro Studio name, development used the internal **Mouse Recorder Pro** name. These were development milestones rather than public Rice2k Macro Studio releases.

## Early recorder builds
Introduced:
- Mouse movement/click capture
- Playback
- Repeat count
- Delay between repeats
- Speed controls
- Record/stop/pause/play controls

## Keyboard expansion
Introduced:
- Optional keyboard recording/replay
- Independent mouse/keyboard recording controls
- Better hotkey behavior

## All Upgrades milestone
Introduced:
- Profiles
- Crash recovery
- Target warnings
- Multiple exports
- Themes
- Action review/editing foundations

## Performance + Hotkeys milestone
Introduced:
- Click-only recording
- Movement skipping
- F8/F9/F10/F12 controls
- Emergency stop
- Performance-focused playback

## Automation Modes milestone
Introduced:
- Click-Only Fast
- Physical Replay
- Browser capture workflow
- Window-aware workflow

## GUI + Error Logs milestone
Introduced:
- Dashboard redesign
- Grouped controls
- Error-log page
- Stronger exception logging

## Stable + Scroll milestone
Introduced:
- Independent scroll recording
- Playback state machine
- Interruptible waits
- Held-input cleanup
- Better multi-monitor metadata
- Smart Actions grouping
- Recovery journal
- Rotating error logs

## Professional UI + Export milestone
Introduced:
- Professional dark/light styling
- Hover tooltips
- Help/guide content
- Dedicated export center
- Raw/Smart CSV/JSON/TXT/Python exports

## Smart Targets + Calendar TODAY milestone
Introduced:
- Windows UI Automation metadata
- Semantic target playback
- Combined Windows/browser Smart Targets
- Dynamic TODAY calendar rule

## Calendar Guide + Debugged Smart Targets milestone
Introduced:
- Dedicated calendar guide
- Calendar self-test
- Reopened-window recovery
- Safer semantic click behavior
- Browser calendar fixes

## Reliable Launcher + Crash Logging milestone
Introduced:
- Self-diagnosing BAT launcher
- Python/Tkinter/dependency validation
- Setup diagnostics
- Startup logs
- Tkinter callback logs
- Thread exception logs
- Settings hardening
- Fallback logs

These milestones became the feature base for **Rice2k Macro Studio v1.0**.

## Release naming policy

Going forward:

- **Major version** — substantial project direction/architecture change
- **Minor version** — meaningful new features or workflows
- **Patch version** — bug fixes, compatibility, documentation, or small refinements
