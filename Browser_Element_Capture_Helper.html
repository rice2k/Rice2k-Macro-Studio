Browser Smart Target Capture

This helper records semantic website targets instead of only mouse coordinates.

It captures URL, page title, event type, tag, role, visible text, accessible labels, ID/name/type, selector, XPath, and date metadata.

It does not store typed field values. Password-related metadata is redacted.

After generating it, drag this link to your browser bookmarks bar:

Calendar: always choose the current date

After starting capture on the website, click Mark Next = TODAY in the floating capture panel, then click the calendar date you want to represent “today.”

On replay, the helper searches for today's date using aria-current="date", data-date, datetime, accessible labels, and a calendar-scoped day-number fallback.
